# Glaszetter Snel

Complete bedrijfsapp voor glaszetters en glasbedrijven.

## Slogan
**Meer dan glaswerk, een heldere werkwijze.**

## Projectstructuur

```
glaszetter-snel/
├── apps/
│   ├── mobile/          # React Native (iOS/Android)
│   └── web/             # Next.js (Desktop/Tablet)
├── packages/
│   ├── shared/          # Shared types, utilities
│   └── api/             # Node.js backend
├── docs/                # Documentation
└── scripts/             # Build scripts
```

## Snelle start

```bash
npm install
npm run dev              # Start web app
npm run dev:mobile      # Start mobile app
```

## Fases

- **Phase 1:** Login, Home, Projecten, Klussen, Basis Inmeten
- **Phase 2:** Berekeningen, Tekeningen, Offertes, Bestellingen
- **Phase 3:** Magazijn, QR, Leveringen, Klantportaal
- **Phase 4:** AI features, Integraties, Analytics
